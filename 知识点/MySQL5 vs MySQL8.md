| 特性              | 5.7 及之前                     | 8.0 做法                                                                       | 一句话场景                        |
| --------------- | --------------------------- | ---------------------------------------------------------------------------- | ---------------------------- |
| **窗口函数**        | 无，只能嵌套子查询                   | 原生支持 `ROW_NUMBER()`、`RANK()`、`DENSE_RANK()`、`NTILE()`、`LAG/LEAD` 等           | 排行榜、同比环比、分页去重                |
| **公用表表达式 CTE**  | 不支持                         | 支持递归和非递归 `WITH … AS …`                                                       | 树形层级展开、 BOM 展开、任意层级菜单        |
| **降序索引**        | 语法接受但忽略                     | 真正按 DESC 存储，避免额外排序                                                           | 多列排序 `c1 ASC, c2 DESC` 直接走索引 |
| **原子 DDL**      | 中途 crash 可能残留 `.frm`、`.ibd` | 一条 DDL 要么全成功要么全回滚                                                            | 大表加字段、删索引不再“半吊子”             |
| **JSON 数据类型增强** | 只存、简单提取                     | 新增 `JSON_TABLE()`/`JSON_ARRAYAGG()`/`JSON_OBJECTAGG()`/`JSON_VALUE()`，支持部分更新 | 日志/配置/流水直接当表查，甚至可建虚拟列并索引     |
| **角色 Role**     | 只能逐个用户授权                    | 支持 `CREATE ROLE` → `GRANT` → `SET DEFAULT ROLE`                              | DBA 批量授权、回收权限一次到位            |
MySQL8 在==高并发场景下==相较于 MySQL5 性能好。这与 8 在线程数量多时 CPU 利用率有关。
